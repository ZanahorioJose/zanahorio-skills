# 这技能做啥？

啥也不干，就是让 Codex 回答"我是谁"：报出当前对话的用户身份和自己的角色设定，从而确认 Codex 流程能跑通、技能声明已经生效。

## 测试步骤

1. 回答"我是谁"：说明当前对话的用户是谁以及我的角色设定，AGENT.md 是否解析正确。
2. 报告技能状态：确认 SKILL.md 是否被正确读取，frontmatter 的 name 和 description 是否解析正确。
3. 给出结论：以上步骤全部正常完成，即表示 Codex 流程和技能声明均生效。
